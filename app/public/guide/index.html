The admin's guide

How to set AGMessage up for a show, run it on the show laptop, bring in the Board's tablets and phones, and look after the people who sign in.

AGMessage serves these pages itself, so they are wherever AGMessage is: on the venue network, and through the internet link while it is on. They name no code, link, token or password of this AGMessage. Words in a box, like Add a person, are a button, a field or a heading as AGMessage draws it; words in quotes are what a page says.

Three kinds of admin

Three things in AGMessage are called admin, and each opens different doors.

The admin token
A code of 16 characters that AGMessage makes each time it starts. It is typed at Admin login on the laptop itself, opened as http://localhost:3023/admin, and nowhere else: from any other device, the laptop's own network address included, it is refused. It is not an account. It does what only the laptop may do: make the first admin account, accept the audit log's findings, adopt accounts held aside, and delete an archive's contents.
An admin account
An account whose role is Admin, signed in with a username and password from any device on the venue network. It makes everyone else's account, and does everything on the admin page but the few acts kept for the token at the laptop.
The laptop's admin
On a laptop with AGMessage installed, the Windows account AGMessage belongs to. It reads the admin token from the Start menu, starts, stops and upgrades AGMessage, and gives those rights to other Windows accounts. It is a Windows account, and gives no right inside AGMessage.

Some acts are "the admin's" alone: the token at the laptop, or an account whose role is Admin. An account given App settings: AI key, HTTPS, the tunnel, the show network opens the admin page, but it cannot archive an event, split the audit log, lock someone's clock or countdown, choose what an On stage seat may do, or let backstage guests show web pages.

Words this guide uses

AGMessage keeps one word for each thing, on every page.

A hall
A venue space: its Main room, its code, its own Stagewatch link, its screens and its help requests.
A room
The Main room is the hall itself. A side room (Legal, Media) is one of its other rooms, named "Hall 2 › Legal".
A code
The 6 characters a guest types to join a room. Each room has its own; the admin page calls it the guest code.
A seat
On stage, Backstage or Observer in a Main room; Member or Observer in a side room.
The Board
Everyone seated On stage in a hall's Main room: presenters and board members.
The backstage team
The crew and staff seated Backstage, who send messages, share files, show things to the Board and answer help requests.
A screen
A browser holding a screen's link (/d/…): the projector PC, the lectern monitor, a foyer TV.
The speaker's screen
Stagewatch's confidence monitor, which AGMessage sends a line to through Stagewatch.
A take
What a screen, or a person's page, is told to show. It is on screen only once that screen or page confirms it.
The halls board
The page that lists every hall an account may see, with the help requests waiting.
