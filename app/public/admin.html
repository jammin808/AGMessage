      How a remote user joins via Cloudflare
      1. cloudflared is bundled with this server — no separate install needed. The portable ZIP ships bin/cloudflared.exe alongside node/node.exe. (If you ever need a manual copy, you can grab one from github.com/cloudflare/cloudflared.)
      2. Toggle Remote access above to ON. The server spawns cloudflared tunnel --url http://localhost:<port> for you and watches its output for the public URL.
      3. Once the URL appears, click 📋 Copy and share it with each remote user, along with the meeting's 6-character room code.
      4. The remote user opens the URL in any browser, enters the room code, their name and role, and joins as they would on the local network.
      5. When the meeting is over, toggle this off to take the tunnel down.

      If you'd rather run cloudflared manually (e.g. with a named tunnel and a stable subdomain), you can leave this toggle off and start your own — the server doesn't depend on it.
