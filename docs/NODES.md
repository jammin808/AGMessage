# AGMessage on the show network

AGMessage implements **Show Bus 1.2** (`docs/SHOWBUS.md`; master copy in Stagewatch). It is a `messenger` node. It
hears PlayMap's `playmap` kind (a Show Bus 1.3 proposal, PlayMap `docs/SHOWBUS-NODE.md`).

| What | How |
|---|---|
| Hello | UDP 9928 every 2 s: `{"t":"messenger","v":1,"proto":1,"id":<stable 8 hex>,"ports":{"http":3023,"https":3023},"caps":["messages","action-prompts","documents","ai","context","receipts","proposals","displays","help"],"clock":<unix ms>,"tls":"sha256:<hex>","build":"0.5.0+17.abc1234"}`. `build` is the build it runs (`app/lib/version.js`). Not sent when bound to loopback. |
| Peers | Every hello kind on 9928 (`main`, `agent`, `patterns`, `playmap`, `messenger`): live < 6 s, stale < 12 s, then dropped; a peer's `build` is kept when it is SemVer's alphabet within 64 characters. Admin → Show network. |
| HTTPS (§10) | The same port serves HTTP and HTTPS (a connection whose first byte is a TLS handshake is TLS). One self-signed ECDSA P-256 certificate per install, made with node:crypto, kept in `%LOCALAPPDATA%\AGMessage\tls.json` with its private key sealed; valid 825 days (Apple's limit) and renewed 30 days before it ends. `GET /tls`, `GET /tls.cer`. **Require HTTPS** (admin). |
| Stagewatch links | One per hall that has its own (the hall's Set up: address, `node`-scope key, fingerprint — kept sealed in `settings.json` → `hallStagewatch`, never in the room's own settings), and the default one (Admin → Show network) for every other hall. Each: `GET ws://<sw>/ws` (or `wss://` when Stagewatch announces a certificate, the address is `https://` or a fingerprint is typed) with `Authorization: Bearer swk_…` — never in the URL; the certificate checked against the pin for that node before anything is sent; ping every 2 s for the clock offset (CLOCKS APART > 2 s); stale after 6 s quiet, redial after 12 s, backoff 0.5 → 5 s with jitter. A hall's frames reach only that hall's room and screens. |
| Send to stage | `POST /api/message/<text>/<urgency>/off/ack` with `X-Request-Id: ag…` to the hall's Stagewatch; the receipt `{"stage":"accepted"\|"applied","refs":{"messageId"}}`; the live frame's `messageId` / `messageAck` / `messageAckBy` then mark that message seen / acknowledged. Sends and acknowledgements are keyed by link and message id (each Stagewatch numbers its own). A down link refuses at once (nothing queued). |
| Show desk (§11) | When a hall's Stagewatch keeps the approval queue (`approvals` in its hello's caps, or `GET /api/proposals?from=` answers), a message can be asked of the operator with a destination (`app/lib/stagelines.js`): the speaker's screen `message "<text>" <info\|warn\|crit> off ack`; a role screen `signal message <moderator\|backstage\|interpreter> "<text>"`; a department its context lists `signal message "<Dept>" "<text>"`; the operator alone `note "<text>"`. `POST /api/proposals` (target `{"t":"main"}`, risk `review`); its state is read every 3 s and shown on the message. Every line is held to a port of Stagewatch's tokenizer and parser (0.4's `… <urgency> ack` was refused: Stagewatch reads the third word as the flash). AGMessage takes one verb from any desk: `notice <text>` (a notice in every open meeting, risk `review`), collected, run once and reported. |
| Patterns and PlayMap | Linked by the admin (Admin → Show network → Link…) with the node's own pairing token, sealed in `settings.json` → `peerLinks`, optionally for one hall. `GET /api/context` every 5 s with `X-Patterns-Token` / `X-PlayMap-Token` (never in a URL; pinned TLS when the node announces a certificate): its light, headline, attention items and verbs on the halls board and in the AI's brief. Driving it (`nodes.control`): only a verb its context lists (the longest match); low and review risk sent now — `POST /api/cmd` (one line, `X-Request-Id`) → its receipt (Patterns' `OK`/`ERR` words, PlayMap's JSON); high risk only proposed to a show desk (target `{"t":"patterns"\|"playmap","id"}`), where a person approves it and the node collects it with its own key. Every link and command is audited; never the token. |
| Its context | `GET /api/context` (admin, or `Authorization: Bearer agn_…` — the read-only token on the admin page). Show Bus §6: meetings and people by role, open action-prompt questions, the count of open help requests, each Stagewatch link and its clock (a hall's by the Stagewatch's own name), AI and tunnel state, role-level recent events, one-hop peers (a linked Patterns or PlayMap with its own light and headline). **Never** message text, names, room names or codes, or documents. Posted to every linked Stagewatch (`POST /api/peers/context`) on change and every 5 s. |
| Stagewatch's context | `GET <sw>/api/context` on connect and every 5 s, per link: the admin page, the AI's brief, and the departments offered as destinations. |
| Health | `GET /api/health`: `{ok,version,build,uptime}` for anyone; restarts, last crash, watchdog give-up, event-loop delay (p50/p95/max), send-to-stage round trip, clock offset and save errors for the admin or the host laptop. |

## Without the internet

Everything above works on the local network alone. Only the AI drafts (Anthropic) and the Cloudflare tunnel need the
internet; when the AI can't be reached it says so and nothing else changes.
